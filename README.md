# Restaurant Survivor

Unity 기반의 레스토랑 서바이벌 게임입니다.

## 🎮 게임 소개

Restaurant Survivor는 플레이어가 레스토랑을 운영하며 다양한 위협으로부터 살아남는 서바이벌 게임입니다. 플레이어는 고객들을 서빙하고, 돈을 관리하며, 악역들로부터 레스토랑을 보호해야 합니다.

### 기간

- 2024.10.30 ~ 2024.11.8 (8일)

### 개발 환경 

- Unity : 2022.3.50f1  
- 프로그래밍 언어: C#  
- IDE: JetBrains Rider  

### 플랫폼

- Windows

## 🎯 게임 목표

1. **생존**: 악역들의 공격으로부터 레스토랑을 보호
2. **수익**: 고객 서비스를 통한 수익 창출
3. **성장**: 업그레이드를 통한 레스토랑 확장 및 개선

## 🚀 주요 기능

### 📋 게임플레이
- **플레이어 시스템**: 레스토랑 내에서 이동하며 다양한 작업 수행
- **고객 관리**: 고객 스포너를 통한 고객 생성 및 서비스 제공
- **음식 시스템**: 음식 제작 및 서빙
- **금전 관리**: 수익 창출 및 관리

### 🏪 상호작용 시스템
- **캐셔 데스크**: 고객 결제 처리
- **카운터탑**: 음식 준비 공간
- **다이닝 테이블**: 고객 식사 공간
- **금고**: 돈 보관 및 관리
- **쓰레기통**: 폐기물 처리

### 👹 악역 시스템
- **캐셔 악역**: 결제 시스템 방해
- **카운터탑 악역**: 음식 제작 방해
- **다이닝 테이블 악역**: 고객 식사 방해
- **금고 악역**: 자금 도난 시도

### 💰 운반 가능한 아이템
- **음식**: 고객에게 서빙할 음식
- **돈**: 게임 내 화폐
- **쓰레기**: 정리가 필요한 폐기물

### 🎯 업그레이드 시스템
- 레스토랑 시설 개선
- 플레이어 능력 향상
